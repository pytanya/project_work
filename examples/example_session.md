# Пример сессии EduTutor (демо-прогон)

Сценарий: **школьник 6 класса, география, тема «Атмосфера», без загруженного
файла** → авто-поиск локального PDF (Plan B) → разбор → квиз → оценка → судья.

Команда:
```
python main.py --scenario schoolchild_grade6_geography --auto --questions 3
```

## 1. Источник (Plan B)

```
┌────────── Источник (Plan B) ──────────┐
│ Локальный PDF: _56_klassy_alekseev_a_i_2024.pdf │
└───────────────────────────────────────┘
```

Агент нашёл учебник «География 5–6 класс, Алексеев» в каталоге Downloads
(`TEXTBOOKS_DOWNLOADS_DIR`), разобрал его через pdfplumber (fallback для файлов
> 50 стр.), разбил на чанки «Параграф N: название» и проиндексировал
(embeddings — RouterAI `multilingual-e5-large`).

## 2. Квиз (RAG-поиск → генерация вопроса)

```
┌──────────────────────── Вопрос ─────────────────────────┐
│ Ты поднялся в горы на высоту два километра. На сколько   │
│ миллиметров упадёт атмосферное давление?                │
└──────────────────────────────────────────────────────────┘
Варианты: 460 мм рт. ст., 660 мм рт. ст., 760 мм рт. ст., 360 мм рт. ст.
```

Вопрос сгенерирован по чанкам учебника с учётом класса (easy/5–6 класс) —
проверка усвоения § «Атмосфера».

## 3. Оценка ответа + объяснение ошибки

```
┌──────────────────────── Агент ──────────────────────────┐
│ Ошибка (оценка 0.0/10). Ответ слишком короткий или не    │
│ содержит ключевых терминов — уточните, пожалуйста.       │
│ Объяснение: Разберём ошибку подробнее.                   │
└──────────────────────────────────────────────────────────┘
```

Ответ автоматической демо-сессии был слишком коротким — сработала rule-based
пре-оценка (В-2). В интерактивном режиме агент запросит уточнение.

## 4. Итог (карта знаний)

```
┌─────────────────────────────── Итог ───────────────────────────────┐
│ Ошибка (оценка 0.0/10). ...                                         │
│                                                                     │
│ Квиз завершён. Правильных ответов: 0/3. Карта знаний: {'Атмосфера': 0.17} │
└─────────────────────────────────────────────────────────────────────┘
```

## Наблюдение

- **RAG работает на реальном учебнике:** вопросы сгенерированы по фактическому
  содержанию (§ Атмосфера), варианты ответов содержат правильные/отвлекающие
  значения (760 мм рт. ст. — нормальное давление).
- **Дешёвый пайплайн:** полная сессия (3 вопроса) стоит ~0.0016 USD.
- Авто-ответы в демо намеренно короткие — чтобы показать пре-оценку; в
  интерактивном режиме ученик отвечает по существу и получает фидбек.
