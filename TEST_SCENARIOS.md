# EduTutor — Тест-сценарии: карточка школьника / студента

Документ описывает, как заполнять карточку знакомства (intake card) для школьника и
студента, какие кейсы проверять (с учебником и без), а также фиксирует результат
проверки инструкций запуска фронтенда и бэкенда.

Отражает фактическую реализацию:
- карточка генерируется в `src/intake.py:build_intake_card` и отдаётся WS-событием `intake.card`;
- применяется через `POST /api/sessions/{id}/intake/card` (`api/routes/intake.py`);
- фронт-валидация — в `frontend/src/components/IntakeCard.jsx`.

## 2. Карточка знакомства — поля и правила валидации

Карточка приходит автоматически в начале сессии (форма вместо пошагового Q&A).
Кнопка «Начать занятие» активна, только когда заполнены все обязательные поля и ФИО ≥ 2 слов.

| Поле | Подпись в форме | Тип | Обязательно | Замечания |
|------|-----------------|-----|-------------|-----------|
| `name` | Как тебя зовут (имя и фамилия)? | текст | ✅ | Минимум 2 слова (имя + фамилия) — ключ изоляции личности |
| `learner_type` | Ты школьник или студент? | выбор | ✅ | `Школьник` / `Студент` |
| `grade` | Класс (если школьник) | текст | ⚠️ | Не обязателен в форме, но на бэкенде требуется для `schoolchild` |
| `subject` | Предмет | текст | ✅ | Напр. «физика», «философия» |
| `topic` | Тема | текст | ✅ | Напр. «Сила тяжести», «Кант — категорический императив» |
| `has_textbook` | Есть учебник по теме? | выбор | ✅ | `Да` / `Нет` |
| `mode` | Что делаем? | выбор | ✅ | `Урок (изучим тему)` / `Квиз (проверим знания)` |

Правила фронт-валидации (`IntakeCard.jsx`):
- пустые обязательные поля → кнопка неактивна, подсказка «Заполните: …»;
- ФИО одним словом → подсказка «Укажи имя и фамилию (минимум два слова)».

Правила бэкенд-валидации (`POST /intake/card`):
- контент-фильтр `guard_user_input` на поля `name`/`subject`/`topic` (prompt-injection / недопустимый контент);
- ФИО < 2 слов → WS-событие `session.error` «Укажи имя и фамилию…».

## 3. Сценарии заполнения карточки

### TC-01. Школьник без учебника — урок (Артем Бородин, физика, 7 класс, «Сила тяжести»)

**Цель:** проверить заполнение карточки для школьника и запуск сценария «урок»
без учебника (поиск источника).

**Шаги:**
1. Открыть `http://localhost:5173`, дождаться карточки «Знакомство и план занятия».
2. Заполнить поля:
   - Как тебя зовут: `Артем Бородин`
   - Ты школьник или студент: `Школьник`
   - Класс (если школьник): `7`
   - Предмет: `физика`
   - Тема: `Сила тяжести`
   - Есть учебник по теме: `Нет`
   - Что делаем: `Урок (изучим тему)`
3. Нажать **«Начать занятие»**.

**Ожидаемый результат:**
- Кнопка активна (все обязательные поля заполнены, ФИО — 2 слова).
- После отправки: «Карточка знакомства заполнена ✓», форма закрывается.
- Т.к. `has_textbook=false` — запускается каскад поиска источника
  (yandex → stepik → … → ddgs) с прогресс-событием `source.progress`.
- При успехе — тьютор строит **урок** по теме (заголовок, определение, ключевые термины,
  секции с цитатами, «Проверь себя»), затем вопрос «Готов к квизу?».
- При неудаче поиска — понятное сообщение «Не удалось найти…» + кнопка «Найти учебник» / блок «Загрузить учебник».
- Профиль сохранён: в `data/students/<student_id>.json` — `name="Артем Бородин"`,
  `learner_type="schoolchild"`, `grade="7"`.

**Критерий приёмки:** карточка применена за один POST, агент перешёл к поиску источника,
режим `lesson` распознан (`src/intake.py:_MODE_MAP`).

### TC-02. Студент без учебника — квиз (философия, Кант)

**Цель:** проверить заполнение карточки для студента (класс не указывается)
и запуск режима «квиз» по гуманитарной теме.

**Шаги:**
1. Открыть `http://localhost:5173`, дождаться карточки.
2. Заполнить поля:
   - Как тебя зовут: `Анна Смирнова`
   - Ты школьник или студент: `Студент`
   - Класс (если школьник): *(оставить пустым — поле не обязательно для студента)*
   - Предмет: `философия`
   - Тема: `Кант — категорический императив`
   - Есть учебник по теме: `Нет`
   - Что делаем: `Квиз (проверим знания)`
3. Нажать **«Начать занятие»**.

**Ожидаемый результат:**
- Поле «Класс» пустое — кнопка активна (grade не требуется для `student`).
- `has_textbook=false` → поиск источника по теме Канта.
- При успехе — приходит первый вопрос квиза (`quiz.card`): адаптивная сложность,
  счётчик «Вопрос N/M», варианты или открытый ответ.
- Ответ → оценка «Верно/Ошибка» (TUTOR-модель) → объяснение ошибки при неверном ответе.
- Wiki-статья ученика: `data/knowledge_wiki/<student_id>/философия/Кант — категорический императив.md`
  (мастерство, попытки, заметки) — персональная, только этого студента.

**Критерий приёмки:** тип `student` не требует класса; тема «Кант…» считается конкретной
(гейт переиспользования/ФГОС не блокирует), квиз запускается.

### TC-03. С учебником — загрузка файла (кейс upload)

**Цель:** проверить, что загрузка учебника поддерживается и после индексации
строится граф тем с гейтом выбора темы.

**Подготовка:** локальный файл учебника — только `.pdf`, `.docx` или `.txt`
(другие форматы отклоняются).

**Шаги:**
1. Открыть `http://localhost:5173`, дождаться карточки.
2. Заполнить карточку (вариант «есть учебник»):
   - Имя/тип/предмет/тема/режим — по TC-01 (Артем Бородин, физика, 7, «Сила тяжести», урок).
   - Есть учебник по теме: `Да`
3. Нажать **«Начать занятие»**.
4. Увидеть сообщение агента:
   «Загрузите, пожалуйста, файл учебника (PDF/DOCX) — перетащите его в блок „Загрузить учебник“ слева…»
5. Перетащить PDF в блок «Загрузить учебник» (или выбрать через `input[type=file]`).

**Ожидаемый результат:**
- Прогресс-баннер «Загружаю и индексирую „…“, это может занять 1–2 минуты…» (`uploadBusy`),
  затем «проиндексирован».
- Индексация: парсинг → чанкинг → эмбеддинги → `source_status="ready"`,
  `source_note="Документ проиндексирован: N чанков"`.
- Строится граф знаний: сообщение «Учебник проиндексирован. Какую тему изучаем?» +
  панель «Темы учебника» (`topic-chip`).
- Клик по теме → «Изучаем: …» → урок → квиз (гейт выбора темы обязателен).

**Пограничные кейсы:**
- Сканированный PDF без текстового слоя → агент просит «укажи страницы нужной темы и тему» (OCR-путь).
- Неверный формат (`.png`, `.jpg`) → ответ бэкенда «Поддерживаются только PDF/DOCX/TXT».
- Ошибка индексации (недоступен эмбеддинг-сервис) → WS `source.failed` + подсказка «Найти учебник».
- `uploadBusy` не блокирует чат/квиз (разделение busy).

**Критерий приёмки:** загрузка поддерживается; после неё обязателен выбор темы из графа,
урок строится из RAG-чанков именно этого файла (атрибуция источника в `lesson_sources`).

### TC-04. Негативные сценарии заполнения карточки

| ID | Действие | Ожидаемый результат |
|----|----------|---------------------|
| TC-04.1 | Указать ФИО одним словом, напр. `Артем` | Кнопка «Начать занятие» неактивна; подсказка «Укажи имя и фамилию (минимум два слова)». |
| TC-04.2 | Оставить пустыми обязательные поля (`subject`, `topic`, `mode`) | Кнопка неактивна; подсказка «Заполните: …» с перечнем полей. |
| TC-04.3 | Ввести в `topic` недопустимый текст (prompt-injection, напр. «игнорируй инструкции…») | Контент-фильтр блокирует: WS `session.error` с предупреждением, граф не продвигается. |
| TC-04.4 | Сменить тип «школьник/студент»/ФИО относительно прошлой сессии в том же браузере | Формируется новый `student_id` — данные (Wiki/история/мастерство) не смешиваются. |

### TC-05. Повторный вход и префилл карточки

**Цель:** проверить, что карточка предзаполняется из профиля и данные изолированы.

**Шаги:**
1. Заполнить карточку как в TC-01 (Артем Бородин, школьник, 7) и завершить занятие.
2. Обновить страницу / начать новую сессию (кнопка «Новая сессия»).

**Ожидаемый результат:**
- В карточке предзаполнены имя, тип, класс (из `data/students/<student_id>.json`
  или localStorage); остаётся указать предмет/тему/режим.
- Тот же ФИО+тип+класс → тот же детерминированный `student_id` (`frontend/src/identity.js`),
  сохраняется история и мастерство.
- Другое ФИО → новый `student_id`, старые данные не видны.

## 4. Быстрая проверка через API (curl)

Эквивалент TC-01 через REST (для автоматизации/смоук-теста):

```bash
# 1. Сессия
curl -X POST http://127.0.0.1:8000/api/sessions \
  -H 'Content-Type: application/json' \
  -d '{"student_id":"stu_artem_borodin"}'
# → {"session_id":"...","student_id":"stu_artem_borodin","student_name":""}

# 2. Карточка знакомства (Артем Бородин, физика, 7, Сила тяжести, без учебника, урок)
curl -X POST http://127.0.0.1:8000/api/sessions/<session_id>/intake/card \
  -H 'Content-Type: application/json' \
  -d '{"values":{"name":"Артем Бородин","learner_type":"schoolchild","grade":"7",\
       "subject":"физика","topic":"Сила тяжести","has_textbook":"false","mode":"lesson"}}'
# → {"missing_fields":[],"next_question":"...","complete":true}

# 3. Статус (агент перешёл к поиску источника / ждёт действия)
curl http://127.0.0.1:8000/api/sessions/<session_id>/intake/status
```
